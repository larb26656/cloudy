# Cloudy

Cloudy connects users with agents through conversations and user interactions.

## Language

**Interaction**:
A request from an agent that requires a user's response. Questions and Permissions are distinct kinds of Interaction.

**Question**:
An Interaction asking the user for information or a choice, rather than authorization to perform an action.
_Avoid_: Permission, approval

**Permission**:
An Interaction asking the user to authorize an action by an agent.
_Avoid_: Question
